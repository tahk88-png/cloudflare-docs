# Prisma Lock Configuration ✅

## Prisma Setup Verified

### Schema Location
- **Path**: `/prisma/schema.prisma`
- **Generator**: `prisma-client-js`
- **Datasource**: PostgreSQL

### Client Generation
- **Root**: Prisma client generated at root level
- **API**: Uses root Prisma client via workspace
- **Postinstall**: Auto-generates client on `pnpm install`

### Scripts
- `pnpm db:generate` - Generate Prisma client
- `pnpm db:migrate` - Run migrations
- `pnpm db:seed` - Seed database
- `pnpm demo:load` - Load demo data
- `pnpm demo:reset` - Reset demo data

### Dependencies
- **Root**: `@prisma/client@^5.20.0`, `prisma@^5.20.0` (dev)
- **API**: `@prisma/client@^5.20.0`, `prisma@^5.20.0` (dev)

### Migration Files
- `20250101000000_init/migration.sql` - Initial schema
- `20250101000001_exclusion_constraint/migration.sql` - Booking overlap prevention

### Seed Configuration
- **Seed script**: `prisma/seed.ts`
- **Demo load**: `prisma/demo-load.ts`
- **Demo reset**: `prisma/demo-reset.ts`

### Usage
All Prisma operations use the schema at `/prisma/schema.prisma`.
The Prisma client is generated once and shared across the monorepo.
