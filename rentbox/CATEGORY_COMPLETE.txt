     - Dynamic facets with counts
     - Multi-select checkboxes

  3. Toiteallikas (Power Type)
     - Aku (Battery)
     - Elekter (Corded)
     - Bensiin (Petrol)
     - Käsitsi (Manual)

  4. Kasutus (Use Case)
     - Dynamic from product tags
     - Multi-select

  5. Hind päevas (Price per day)
     - Min-max slider
     - Real-time updates

  6. Asukoht (Location)
     - If multiple lockers exist

  7. Lisad (Extras)
     - Sisaldab akut
     - Sisaldab laadijat

SORT OPTIONS:
  1. Kõige kättesaadavam (Most available) [DEFAULT]
  2. Täna saadaval (Available today)
  3. Hind: madal → kõrge (Price low to high)
  4. Hind: kõrge → madal (Price high to low)
  5. Populaarsus (Popularity)
  6. Uusimad (Newest)
