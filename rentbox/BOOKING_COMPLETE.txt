║                                                                       ║
║  BOOKING FLOW                                                         ║
║  1. User selects product                                             ║
║  2. Chooses date, duration, start time                               ║
║  3. System checks real-time availability                             ║
║  4. Shows price quote with VAT                                       ║
║  5. User fills contact form                                          ║
║  6. Creates booking (auto-assigns compartment)                       ║
║  7. Simulates payment confirmation                                   ║
║  8. Shows access code + instructions                                 ║
║                                                                       ║
║  AVAILABILITY CHECKING                                                ║
║  - Checks for time range overlaps                                    ║
║  - Only active bookings block slots (pending, paid, active)          ║
║  - Auto-assigns first available compartment                          ║
║  - Shows next available if fully booked                              ║
║  - Transaction-safe conflict prevention                              ║
║                                                                       ║
║  PRICE CALCULATION                                                    ║
║  - Hour-based: price × hours                                         ║
║  - Day-based: price × ceil(hours/24)                                 ║
